Indegene · Design Systems

One design language across every healthcare platform

Several products, several squads and nothing tying them together. This is how I pulled a set of drifting healthcare interfaces into one documented system that keeps every team shipping the same product.

People often think of a design system as a component library. I think of it as an agreement that lets a designer on one team and an engineer on another ship the same product without needing a meeting.

The challenge

Every squad drew its own buttons

Healthcare products grow quickly, and usually in parallel. Each squad was working to its own deadline, and without a shared foundation the products slowly drifted apart. A different blue here, a slightly taller input there, and an alert dialog that behaved three different ways depending on who built it.

For teams working under regulatory scrutiny, that kind of inconsistency is more than untidy. It's a real risk. It slows down QA, confuses clinicians who move between tools, and turns a new hire's first month into an archaeology project.

The approach

Build the foundation, then the governance

  1. Audit the drift

    Catalogued every component, colour and pattern already out in the wild. I wanted to start from what actually existed, not from some ideal version.

  2. Set the tokens

    Defined a semantic token layer for colour, type, spacing and elevation, so decisions live in one place and can be themed, instead of hiding in scattered hex values.

  3. Build the library

    Designed and documented the core component set, with every state, variant and accessibility note a builder needs to ship without guessing.

  4. Write it down

    Usage guidelines, do and don't examples, and handoff specs. These are the docs that let people who have never met me use the system properly.

  5. Drive adoption

    Worked with each squad to migrate screen by screen, and kept the system growing and changing instead of letting it gather dust.

The solution should outlive the project, and it shouldn't depend on me being in the room.

The outcome

One product, however many teams

3+platforms sharing a single system and token set
Daysinstead of months for a new designer to get productive
1source of truth, so what ships matches what was designed
